# Anfragen archive

Local copies of the parliamentary questions on wind turbine distances and 10H, with their answers: Bundestag
Schriftliche Fragen and Kleine Anfragen, Bavarian Schriftliche Anfragen and Anfragen zum Plenum, Saxon Kleine Anfragen,
and Kleine Anfragen of other Länder. 82 PDFs, downloaded on 12.10.2026 directly from the parliaments' document servers. The other referenced
PDFs are in the [PDF archive](../pdfs/README.md).

Each subfolder has a `manifest.tsv` without header: file name, source URL, size in bytes, SHA-256. Verify from a
subfolder with:

```sh
awk -F'\t' '{print $4"  "$1}' manifest.tsv | shasum -a 256 -c --quiet
```

The Date column is the date printed on the Drucksache. PDFs are downloaded source documents; treat them as untrusted
data.
